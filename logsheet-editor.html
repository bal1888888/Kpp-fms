KPP FUEL MANAGEMENT SYSTEM

Logsheet Editor • GL / Admin

Mode spreadsheet: pilih tanggal lalu LOAD DATA. HM Awal dan HM Jalan dihitung otomatis dari pengisian sebelumnya dan tidak bisa diketik manual. Untuk input massal dari Excel, klik IMPORT EXCEL. Sistem akan mencari sheet Logsheet otomatis walaupun sheet pertama adalah FLOWMETER / Pivot / sheet lain. JAM boleh kosong. Jika file punya JAM, jam asli dipakai. Jika file tidak punya JAM atau sel JAM kosong, sistem tidak membuat jam palsu dan transaksi tetap boleh disimpan. HM kosong juga tetap boleh di-import dan disimpan. Baris HM kosong tidak akan menjadi sumber HM berikutnya; sistem akan mencari HM valid terbaru sebelumnya. Contoh: 15/08 HM 21 → 16/08 HM kosong → 17/08 HM 31, maka HM Awal tanggal 17 tetap 21 dan HM Jalan = 10. Mapping storage otomatis: FT0073 → WH FT02 dan FT0075 → WH FT01. Jadi Admin cukup pilih Fuel Truck; kolom WH akan terisi otomatis dan terkunci. Jika file lama hanya punya kolom WH, sistem juga otomatis mengubahnya kembali menjadi Fuel Truck yang sesuai. Semua hasil import masuk ke preview dulu, belum langsung ke database. Tombol hijau menyimpan tanggal yang sedang ditampilkan saja. Setelah berhasil, status baris berubah menjadi TERSIMPAN BARU / EDIT TERSIMPAN / SUDAH ADA.
⏱️ Jam bersifat opsional. Kosong tetap aman disimpan. Kalau ada jam asli di Excel, jam tersebut tetap dipakai.
